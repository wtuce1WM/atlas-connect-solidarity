# Travailler depuis plusieurs ordinateurs en parallèle

Oui, il est tout à fait possible d'utiliser Lovable depuis 2 (ou plus) ordinateurs en même temps avec le même compte. Il n'y a pas de verrou de session.

## Points clés

- **Éviter d'éditer le même fichier en parallèle** depuis les deux postes : le dernier message envoyé "gagne" et peut écraser les modifications de l'autre poste. Travailler sur des zones distinctes (ex. poste A = edge functions, poste B = pages front).
- **Un chat différent par poste** : ouvrir un nouveau chat ("+ New chat") sur chaque ordinateur pour éviter que les deux postes écrivent dans le même fil et le rendent illisible.
- **Preview partagée** : les deux postes voient la même preview en temps réel. On peut tester depuis l'un pendant que l'autre code.
- **Mémoire projet partagée** : la mémoire (`mem://`) est commune aux deux postes, donc les préférences et règles restent cohérentes.

## Recommandation pratique

Découper les tâches par domaine pour éviter les collisions :

- Poste A → chat dédié "backend / IA / edge functions"
- Poste B → chat dédié "UI / front / pages"

Cela permet de vraiment avancer en parallèle sans conflit.
