# Restaurer le header natif après fermeture d’un article

## Modification
- Mémoriser la page réelle depuis laquelle l’article est ouvert.
- À la fermeture, revenir à cette page au lieu d’ouvrir l’assistant autonome.
- Conserver le fil de conversation existant.

## Vérification
- Ouvrir l’article depuis l’assistant Home, puis le fermer.
- Vérifier le retour sur Home avec le header natif logo + 1WM, sans header « Assistant IA One World Morocco ».
